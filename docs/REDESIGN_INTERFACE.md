# Interface simplificada

A navegacao principal apresenta somente as areas usadas no fluxo diario:

- Nova venda;
- Caixa;
- Historico;
- Cadastro;
- Estoque;
- Usuarios.

Cadastro agrupa Produtos e Categorias. Historico agrupa Vendas e Produtos vendidos.
A simplificacao removeu telas administrativas paralelas, mas manteve todas as
consultas e acoes do Historico.
