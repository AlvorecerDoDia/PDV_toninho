# PDV Toninho

Projeto de ponto de venda desenvolvido em Java com Maven e JavaFX.

## Estrutura principal

- `src/main/java`: código-fonte da aplicação.
- `src/main/resources`: arquivos FXML e demais recursos.
- `src/test/java`: testes automatizados.

## Requisitos

- Java 21
- Maven 3.9 ou Maven Wrapper incluído no projeto

## Executando

No Windows:

```powershell
.\mvnw.cmd javafx:run
```
